# ESP32 연계 6주 교육안

주 3시간, Python 기초 학습자를 기준으로 한 조정 가능한 교육안입니다. 1~3주는 PC 시연 모드로 시작하고 4주부터 같은 판단 구조를 실물 계측에 연결합니다. PC 환경과 실물 환경을 명확히 구분하여 학생이 모델의 가정과 관측된 결과의 차이를 설명하게 합니다.

## 학습 목표

- 일별 에너지 예측과 초 단위 장치 제어가 다른 시간 수준임을 설명한다.
- 교육용 kWh→Wh 환산과 실제 전력 적분을 구분한다.
- 운영 목표, 전력·에너지 제약, 조명 요구, 작업 완료 시한을 함께 고려한다.
- PWM 명령과 실제 회전·소비전력을 구분하고 피드백을 해석한다.
- 통신 단절·센서 이상·작업 정체에서 원인을 구분하고 재가동 절차를 설명한다.

## 주차별 구성

| 주차 | 내용 | 개인 산출물 |
|---|---|---|
| 1 | 합성·실측 자료 구분, 일별 CSV·계량 경계·단위 점검 | 데이터 설명서 |
| 2 | 전주 기준 예측, 시간순 평가, 교육용 예산 환산 | 예측·환산 계산과 한계 설명 |
| 3 | PC 시연에서 조명·작업 제약과 피드백 연결 | 운영 정책 비교 보고서 |
| 4 | 센서·드라이버·엔코더 배선과 교정 | PWM–전력–회전 계측표 |
| 5 | 실물 폐루프, 명령 만료·오류 정지·재승인 | 로그 근거의 오류 진단 |
| 6 | 새로운 예산·시한·부하 조건의 개인 수행 | 정책 수정·전이 과제·성찰 |

## 공통 실습 과제

### 과제 1: 예측은 어떻게 물리적 행동으로 이어지는가?

하루 예측 kWh, 환산된 Wh 예산, 조명 최소 요구, 목표 누적 회전수와 완료 시한을 표로 정리합니다. 어느 값이 실제 관측이고 어느 값이 교육용 시나리오인지 구분합니다. 일별 예측이 모터의 매 순간 RPM을 예측한다고 설명하면 안 됩니다.

### 과제 2: 작업량을 줄이지 않고 운영하기

동일한 조명 요구와 목표 회전수를 유지하여 조건을 비교합니다. 소비 에너지가 줄었을 때 작업 미완료나 서비스 축소가 생겼는지 함께 확인합니다. 같은 조건에서 예산 초과량, 완료 시간, 누적 회전수, 사용 에너지를 제시합니다.

### 과제 3: 명령과 결과가 다를 때

PWM 명령, 센서 전력, 엔코더 RPM·누적 회전을 함께 봅니다. 출력이 있는데 회전이 부족한 상황을 “예측 오류”로 단정하지 않고, 엔코더 연결·기동 조건·제약 적용·기계적 부하 등 대안 원인을 검토합니다. 실물 정체 시험에서 모터축을 손으로 잡지 않습니다.

### 과제 4: 통신이 회복되어도 바로 가동하면 되는가?

명령 만료로 정지한 뒤 통신이 회복되는 과정을 확인합니다. 오류 해제와 별도 가동 승인의 의미를 설명하고, 실제 동작을 로그로 확인합니다. 로컬 단조 시간에 의한 만료와 PC 벽시계의 차이를 설명합니다.

## 개인 수행평가

각 영역을 0~4점으로 평가하며 중간 점수의 세부 기준은 수업 전 정합니다. 팀 실물 작품과 개인 학습 성과는 구분합니다.

| 영역 | 0점 | 2점 | 4점 |
|---|---|---|---|
| 데이터·단위 | 전력·에너지를 혼동 | 단위·시간 수준을 구분 | 누적값·계량 경계·환산 한계까지 설명 |
| 예측·예산 | 예측과 제어를 혼동 | 예측에서 예산을 계산 | 과소·과대 예측의 운영 영향을 근거로 설명 |
| 제약·서비스 | 무조건 출력을 줄임 | 작업·조명 조건을 반영 | 같은 서비스에서 운영 결과를 공정하게 비교 |
| 피드백 | 명령을 실제 결과로 간주 | 계측 결과로 상태를 갱신 | 실제 회전·전력 차이와 수정 과정을 설명 |
| 오류 진단 | 근거 없는 원인 추측 | 한 로그로 원인 제시 | 대안 원인을 비교하고 확인·복구 절차 제시 |

일부 또는 전체 답안을 두 평가자가 독립 채점하여 일치도를 확인합니다. 사전·사후 검사는 다른 문항의 난이도를 맞추고, 마지막에는 수업 중 보지 않은 조건을 제공합니다. 만족도와 흥미는 보조 지표이며 수행 능력의 대체값이 아닙니다.

## 수업 기록

익명 학습자 ID, 버전, 자료 출처, 실행 모드, 예측·환산 설정, 전력·서비스·작업 조건, 명령·관측 로그, 가설과 결과, 교수자 도움 횟수, 완료 시간을 보관합니다. 실제 학생 자료를 연구에 사용할 경우 기관의 동의·심의 기준을 확인하고 성적 평가와 연구 참여를 구분합니다.
