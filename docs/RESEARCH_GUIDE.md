# KCI 후속 연구 설계

## 권장 주제

**「캠퍼스 전력 시계열 예측과 ESP32 폐루프 제어를 연계한 Physical AI 교육 플랫폼 개발 및 적용」**

핵심 기여는 ESP32로 전력을 웹에 표시하는 것만이 아닙니다. 일별 예측을 운영 목표로 바꾸고, 학생이 명령과 실제 결과의 차이를 계측하여 제약·작업·오류 대응을 이해하도록 하는 교육 설계와 평가입니다.

기존 캠퍼스 예측 원고의 데이터 검증·시간순 평가를 이어받되 새로운 원고의 결과는 플랫폼 검증과 교육 적용 자료로 구성합니다. 일별 자료가 실제 시간대별 운전을 복원한다고 주장하지 않으며, 기존 예측오차 감소를 에너지 절감으로 표현하지 않습니다. 실제 원고·원시 자료를 공개 저장소에 포함하지 않습니다.

## 연구 질문

1. 예측–예산–명령–계측의 연계를 배우면 시스템 관계와 단위·제약 이해가 어떻게 변하는가?
2. 학습자는 새로운 예산·작업 시한에서 같은 서비스와 작업량을 유지하는 정책을 구성할 수 있는가?
3. 처음 보는 통신·센서·회전 이상을 로그에 근거하여 구분하고 복구할 수 있는가?

교육 효과를 주제로 삼으면 개인 전이 과제의 루브릭 점수를 주 결과변수로 사전에 정하고, 개념 검사·완료 시간·도움 횟수·만족도를 보조 변수로 둡니다. 제어 성능 자체를 주제로 삼는 경우에는 별도의 가설과 비교 설계가 필요합니다.

## 플랫폼 검증과 교육 평가를 분리

| 구분 | 필요한 증거 |
|---|---|
| PC 시연 검증 | 상태 갱신, 에너지 적분, 제약·오류 로직 자동 시험 |
| 펌웨어 검증 | 전체 ESP32 빌드·업로드, 로컬 만료·정지·재승인 |
| 계측 검증 | 전압·전류 대조, 엔코더 회전 환산, 반복성 |
| 운영 검증 | 같은 요구조건의 예산 초과·작업 완료·에너지 비교 |
| 교육 평가 | 개인 개념 이해·정책 설계·새 오류 진단 수행 |

호스트 C++ 컴파일은 ESP32 전체 펌웨어 빌드와 구분합니다. 시연 모드 값은 실물 측정값과 구분합니다. GPIO 출력이 변했다는 사실만으로 실제 회전·작업이 완료되었다고 판정하지 않습니다.

## 운영 비교 설계

다음 요소를 하나씩 바꾸고 나머지를 고정합니다.

- 예측 활용 여부: 고정 예산 대 예측 기반 예산
- 피드백 활용 여부: 시작 계획 유지 대 관측 기반 조정
- 외란: 부하 반응 차이·통신 단절·계측 이상

양쪽 모두 같은 최소 조명 요구, 목표 회전수, 완료 시한, 전원, 전력 상한, 초기 상태를 사용합니다. 로컬 오류 정지 등 현장 보호는 양쪽에서 유지합니다. 예산·전력이 부족한 경우에는 목표 미달도 결과로 기록하고, 실패를 제외하여 평균을 좋게 만들지 않습니다.

주 운영 지표는 예산 초과 Wh와 작업 완료율로 좁힐 수 있습니다. 누적 회전수·완료 시간·조명 요구 미충족·최대 구간 전력·전력 상한 위반·전체 에너지를 보조 지표로 둡니다. 조명의 PWM 비율은 조도 대체 지표이며 실제 쾌적성이나 조도 성능을 입증하지 않습니다. 두 부하 합계 전력에서 각 부하의 전력을 분리하려면 개별 구동 교정이나 별도 계측이 필요합니다.

부하를 꺼서 작업량이나 서비스가 줄었다면 에너지 감소를 동일 서비스의 절감으로 주장하지 않습니다. 초기·최종 회전 상태, 미완료 작업, 모터 관성 등 종단 상태도 기록합니다. 현재 모형에는 배터리가 없으며 배터리 SOC·충방전 경제성 결과를 생성하지 않습니다.

실행 순서를 무작위화하거나 교차 배치하고 동일 조건에서 반복합니다. 실험 회차를 분석 단위로 삼고, 초당 로그 수천 개를 독립 실험 수천 회로 세지 않습니다. 조건별 차이의 크기와 변동·불확실성을 제시합니다. 실제 캠퍼스 전체 설비의 절감 효과나 실시간 서비스 성능으로 일반화하지 않습니다.

## 교육 적용 설계

가능하면 동일한 시간과 목표의 기존 예측·화면 실습과 폐루프 실습을 비교합니다. 사전 능력·학년·교수자·수업 시간·평가 난이도를 기록하거나 통제합니다. 인원은 주 결과변수·예상 효과·분석 방법을 근거로 계획합니다.

수강 인원이 작고 비교집단이 없다면 **개발 및 적용 사례**로 보고합니다. 사전·사후 차이만으로 인과 효과를 확정하지 않습니다. 팀 작품과 개인 점수를 분리하고, 처음 보는 조건의 개인 수행을 포함합니다. 평가자 두 명의 독립 채점과 일치도 확인을 권장합니다. 동의·심의·익명화는 소속기관 기준을 따릅니다.

## 논문 구성

1. 서론: 예측 수업과 물리적 행동 학습 사이의 문제, 연구 질문
2. 관련 연구: 에너지 예측 교육, IoT 교구, 피드백 제어·Physical AI 교육
3. 플랫폼: 계량 경계, 환산 규칙, 상위 운영·ESP32 역할, 오류 처리
4. 콘텐츠: 주차별 목표·활동·산출물·수행평가 연결
5. 검증 및 적용: PC·보드·실물 검증 상태와 교육 실험 절차
6. 결과·논의: 실제 확보한 결과와 한계
7. 결론: 확인한 학습·운영 범위, 다중 노드·추가 센서 확장

필수 결과표에는 버전·실행 모드·계측 교정·같은 서비스 조건·실행 회차·실패 또는 미수행 항목이 포함되어야 합니다. 게재 가능성이나 선행연구 대비 우수성은 실험 전 보장할 수 없으며, 현재 코드가 교육 효과나 실물 성능을 이미 입증했다고 표현하지 않습니다.
