# 구현 및 검증 상태

2026-10-31, Linux / Python 3.12.14 / g++ / Chromium에서 검증했습니다.

## 완료한 소프트웨어 검증

- Python 자동 테스트 **18개 통과**: 제어 상태 전환 9개, 일별 예측 4개, 실제 HTTP 요청을 사용하는 API 통합 테스트 5개.
- C++ 네이티브 보호 로직 검사 **10개 통과**. 이는 ESP32 전체 스케치의 타깃 빌드와 구분합니다.
- JavaScript 구문 검사 통과.
- Chromium과 실제 서버를 연결하여 데모 초기 정지, ARM, 전력·RPM 피드백, STOP 고장 유지, 오류 해제 후 정지 유지, 실험 초기화, 예측 후 별도 예산 적용, CSV·JSON·학습 노트 다운로드를 확인했습니다.
- 같은 브라우저에서 실물 모드에 계측값이 없으면 값을 가상으로 채우지 않고 ARM을 막는 동작을 확인했습니다.
- 390px 모바일 화면에서 가로 넘침이 없으며 페이지 JavaScript 오류가 없었습니다.
- `python experiment.py --seconds 180 --budget-wh .2`를 실행하여 합성 환경의 정책별 결과를 생성했습니다. 소비 감소와 작업 미완료를 함께 기록하며 실제 절전 효과로 해석하지 않습니다.

## ESP32 타깃 빌드

공식 Arduino CLI 1.2.2를 다운로드하고 공식 체크섬 파일과 SHA-256을 대조했습니다. 상속된 프록시와 TLS 검증을 유지하여 공식 인덱스를 요청했으나 다음 도메인에서 네트워크 정책 차단을 받았습니다.

- `downloads.arduino.cc`: Arduino 패키지·라이브러리 인덱스
- `espressif.github.io`: ESP32 보드 인덱스

따라서 **ESP32 전체 타깃 컴파일은 미완료**입니다. `.github/workflows/ci.yml`에는 전체 보드 빌드 절차를 포함했지만, CI 실행 성공을 아직 확인하지 않았습니다. 지정한 ESP32 3.3.2, Adafruit INA260 1.5.3, ArduinoJson 7.4.2의 공식 Git 태그 존재는 확인했습니다.

## 별도 실물 검증이 필요한 항목

- 실제 ESP32 펌웨어 빌드·업로드와 통신
- INA260의 전압·전류·전력 교정 및 독립 계기 대조
- 납품 모터의 엔코더 계수·방향·RPM 교정
- LED·모터 드라이버와 전원·배선 정격 대조
- 전원 인가·재부팅·통신 단절 시 출력 정지의 실측
- 같은 서비스·작업 조건에서의 반복 운전
- 학생의 개념 이해·문제 해결 능력 평가

장치용 `config.h`와 토큰·Wi-Fi 자격 정보는 Git에 포함하지 않습니다. 본 저장소는 실습용 소프트웨어와 시험 절차를 제공하며 실물 시스템의 검증 완료나 교육 효과를 주장하지 않습니다.
